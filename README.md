# Dawood — Portfolio

A lightweight, responsive portfolio website built with HTML, CSS and JavaScript.

## Run locally

Open `index.html` in a browser, or run a small local server:

```bash
php -S localhost:8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

Push this repository to GitHub, then go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
